# WorkBuddy 上手与排障

## 安装本教练

依据 2026-10-07 核实的 [WorkBuddy 官方技能说明](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market)，通过技能区域的添加／上传技能入口导入本地技能包，并在已安装列表确认启用。具体入口及包格式以当前客户端为准。

本包为一个技能文件夹，包含 SKILL.md 与 references，没有脚本。当前已做本地结构检查，尚未完成 WorkBuddy 导入与端到端实测。

开始时说：“请使用 workbuddy-ai-starter，带我用 WorkBuddy 完成一个小任务。我是 AI 初学者，一次只带我做一步。”

未被识别时，确认已安装和启用，并使用当前界面提供的选择方式；不假定某种 @ 或斜杠语法在所有版本可用。

## 给材料与检查结果

先用一段文字完成初次练习，再使用当前环境获准处理的工作文件。支持上传或工作目录读取时，通过实际入口提供材料。请 AI 说明读到了哪些材料及主要内容，不能只凭文件名判断。

可复制：“请先确认能读取哪些材料，不能读取的直接告诉我，不要猜正文。”缺少文件工具时改为粘贴相关段落。

生成内容后，检查是否真的产生了所需文件；实际路径或下载结果可用后再说生成成功。只有文字时称草稿，不虚构附件。

## 常见问题

| 现象 | 检查与下一步 |
| --- | --- |
| 导入失败 | 检查包内入口文件、目录层级和当前客户端要求；不要反复盲目重装 |
| 安装后没反应 | 确认启用，明确指定本技能，并查看实际调用依据 |
| 不知道公司要求 | 提供相关模板或规则，并确认读取 |
| 文件读取失败 | 依据实际报错判断格式、权限或能力，必要时粘贴片段 |
| 第三方技能缺工具 | 明确缺哪项依赖，能在授权范围适配再处理，否则交可用替代草稿 |
| 结果不对 | 回到原材料、目标及错误位置，补必要信息后局部修改 |
| 换对话丢进度 | 使用独立学习记录，不承诺自动继承全部历史 |

无法判断界面状态时只问停在哪一步或具体报错。技术故障不记为学员能力不足。

## 从推荐到使用第三方 Skill

先读 resources.md 中目标条目，核对依赖、权限与许可；有实际缺口才安装。不能照抄 Claude 的插件市场命令作为 WorkBuddy 命令。安装后用小样检验，区分安装成功、实际调用和产物合格三个状态。
